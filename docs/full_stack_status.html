학습 결과

  • Heston 파라미터 sampling: 3,000 × 25 strikes (LHS, Feller 무시) — 데이터 생성 338초
  • MLP [5 → 256 → 256 → 256 → 25], 40 epochs CPU — 추가 ~30초
  • 최종 IV RMSE: 0.495 vol points ✓

Calibration 속도 비교 (κ=1.8, θ=0.05, ξ=0.35, ρ=-0.65, v₀=0.04 복원)

MethodWall time정확도
Semi-analytic Nelder-Mead (200 iter) 35.03s loss 1.0e-5
Deep Calib (NN gradient descent, 300 step) 1.36s IV RMSE 0.56 vp
Speedup 26× (CPU)
κ identifiability: 복원된 κ=3.38 vs 실제 1.80. Heston 모델에서 κ 와 θ 는 kappa-theta redundancy 가 있어 IV surface 만으로는 정확히 분리 안 됨. 실무에서 알려진 현상. IV surface 는 유사하게 복원됨 (RMSE 0.56 vp).
