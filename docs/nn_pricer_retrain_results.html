2026-04-24 · 해결 방안 실제 적용 (from nn_pricer_underfit_analysis.html) · CPU-only, 동일 환경 (n=80k samples, 40 epochs, seed=42)

Deep ITM 역효과 — log-MSE 는 deep ITM 에서 약간 악화 (2.02 → 2.50 vp). 이유: deep ITM 가격은 크기 때문에 log-space 에서 상대적 중요도가 낮아짐. 실무에서는 deep ITM 은 intrinsic 이 대부분이라 NN 이 아니어도 근사 쉬움 → 수용 가능.

4. 학습 곡선 비교

왜 "MSE 보기엔 약간 나쁜데" IV-space 에선 더 좋은가?
raw MSE 는 ITM 에 치우친 지표. log-MSE 는 전 구간을 균등 학습해서 평균 MSE 는 살짝 손해지만 deep OTM·ATM 에서 크게 이득. 실무가 관심 있는 건 평균 MSE 가 아니라 IV 오차.

5. 이력서용 bullet 초안

"Hutchinson-Lo-Poggio (1994) NN 옵션 프라이서 재현. log-space MSE loss 채택으로 Hutchinson 원본 대비 ATM IV 오차 2× 개선 (3.13 → 1.58 vol pts), ATM 1년물 call 오차 10.7% → 2.9%. 모델 크기 동일, 데이터 80k 로 CPU 12분 학습. BSM closed-form 대비 추론 28.8× 가속."
