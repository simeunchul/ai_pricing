Crypto Strategy 3-Period 비교 — Sample Size 가 결론을 뒤집는다

2026-04-30 · ai_pricing 프로젝트 · Layer-E (Auto-Trading) — Crypto 확장 v2

한 줄 결과. 같은 strategy, 같은 종목, 다른 backtest 기간 (21일 / 60일 / 365일). 결과가 정반대로 바뀜. Buy-and-hold 는 21일 1위 → 365일 6위. Trend+funding filter 는 21일 4위 → 365일 1위 (+42% return). 학계의 "data length matters" 가설 + "smart filter 가 long-term alpha 만든다" 가설 모두 검증됨. Sample size 부족 = backtest 결과 거의 random.

1. 동기 — 21일 backtest 가 충분한가?

첫 backtest (21일 1h) 결과로 "Buy-and-hold 압도적 1위, multi-factor 기각" 결론 도출했지만, 사용자가 "이게 한 달 데이터?" 라고 의심했음. 그 의심이 정확. 21일 = 약 2-3 trend cycle 만 포함 → sample 너무 작음.

이 보고서: 같은 strategy, 같은 종목으로 3가지 기간 backtest 비교 → 어떤 결론이 robust 한지 확인.

4. 21일 vs 60일 vs 365일 — 결론이 정반대로 뒤집힌 이유

4.1 Sample size 의 위력

PeriodBarsTrade cyclesMarket regimes결과 신뢰도
21일 1h477~2-31 (단일 상승)매우 낮음
60일 1h1,440~7-101-2 (대부분 상승)중간
365일 1d365~30-403-4 (상승+조정+회복)높음

4.2 365일이 보여준 진실

지난 1년 crypto 시장 (2025-04 ~ 2026-04) 의 큰 사건:

  • 2025 중반: BTC 폭락 (~-50%) 후 회복
  • 2025 후반: AltSeason 부분적 회복
  • 2026 초: 추가 상승

→ 다양한 regime 노출. Buy-and-hold 가 직격탄 (DD -62%). Trend following 은 폭락 시점에 SHORT 또는 FLAT 으로 회피 → drawdown 감소.

21일 backtest 는 위 폭락 시점 missing → buy-hold 의 위험을 완전히 놓침.

4.3 D_trend+funding 가 365일 1위인 이유

학계 (Soska et al. 2024, Carter 2023) 의 결론과 일치:

  • Trend signal: 진정한 trend 시 진입 → 큰 움직임 잡음
  • Funding filter: 시장 과열 (모두 LONG) 시 매매 회피 → 과밀 trade 의 비효율 회피
  • 21일 backtest 에선 funding 신호 자체가 임계 도달 X (평균 -0.0015%) → 효과 측정 못함
  • 365일 sample 에선 funding 큰 변동 (±0.1%+) 발생 → filter 진짜 작동

5. 데이터 한계 분리

5.1 1h 봉의 21일 한계 — Binance API 제약

Binance Futures API:
  futures_top_longshort_account_ratio(period="1h", limit=500)
                                                    ─────────
                                       max 500 bars × 1h = 21 days

5.2 1d 봉으로 우회 — sample size ↑

일봉 사용 시:
  futures_klines(interval="1d", limit=1000) → ~3 years
  futures_funding_rate(limit=1000) → ~1 year (8h 단위 → 1d aggregate)
  L/S ratio: 1d 라도 500 bars max → ~1.4 years (가능, 다만 이번엔 제외)

→ daily 단위로 1년 backtest 완전 가능
→ trade 빈도 ↓ but regime diversity ↑

6. 의미 있는 학습 — 정직한 narrative

  1. 21일 backtest 결론은 거의 random. Sample 너무 작음. AVAX Bollinger +17% 같은 결과는 우연 (60일 -14%로 반전).
  2. 365일 데이터에서 multi-factor 가 진짜 작동. D_trend+funding +42% 평균, BNB/AVAX 에서 +100%+. 학계 결론 검증.
  3. Buy-and-hold 의 함정: 단기 우월 보이지만 1년 평균 -19%, MaxDD -62%. 폭락 직격.
  4. 전략 ≠ 단일 답. 종목별 best 다름:
    • AVAX/BNB: trend + funding
    • BTC: Bollinger MR
    • ETH: buy-hold
    • SOL: funding contra
  5. Sample size 가 보고서 결론을 뒤집을 수 있음. 신뢰도 낮은 backtest 로 "이게 정답!" 단정 위험.
  6. 기존 21일 보고서의 결론 ("buy-hold 가 모든 active 이김") 은 사실상 기각. 60-365일 에선 active 가 우월.

7. 우리 운영 중인 dry-run 의 의미

현재 (오늘 14:02 시작) 운영 중인 long-short multi-asset 24h dry-run = B_trend (long-short) 룰. 3-period 결과:

  • 21일: B_trend Sharpe -2.58 (worst case)
  • 60일: B_trend Sharpe +1.06
  • 365일: B_trend Sharpe +0.31 (양수)

→ 24h 단편 결과는 noise 가 큼. 결과가 -2% 든 +2% 든 통계적 의미 거의 없음. 다만 학습 narrative 로는 가치 있음 ("backtest 결과 vs 실거래 단기 결과").

9. 비전공자용 요약 (TL;DR)

같은 자동매매 룰을 1달 / 2달 / 1년 데이터로 각각 backtest 했다. 결과가 완전히 다름.

  • 1달: 가만히 들고 있기 (buy-hold) 가 1위, 똑똑한 룰들 다 음수
  • 2달: 트렌드 따라가기가 1위, buy-hold 2위
  • 1년: 트렌드 + 시장 과열 필터 결합이 1위 (+42%), buy-hold 는 -20% (위험)

→ 1달 데이터로 "이게 진짜 답!" 단정하면 매우 위험. 더 긴 데이터에서 정반대 결과 나올 수 있음.

비유: 친구 A 가 어제 1번 카지노 가서 돈 땄다고 "카지노 = 돈 버는 곳" 결론 내리면 위험. 100번 가야 평균이 보임. 1년 데이터 = 100번 카지노 같은 sample size.

실용 결론: 우리 자동매매 봇은 **trend + funding filter 결합** 으로 가는 게 학계와 365일 backtest 모두 지지. 단기 backtest 의 "buy-hold 우월" 은 우연이었음.
