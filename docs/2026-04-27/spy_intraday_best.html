한 줄 결과 — 6가지 환경에서 NN 헤지를 BSM Δ 와 비교한 결과, SPY 실데이터 + 15분 step 조합에서 CVaR@5% 9.11 → 5.04 (+44.6% 개선) 달성. 5가지 학술 PoC 를 거쳐 진짜 best 발견. 절감 절대값 −4.07 per 100 notional → ELS 쿠폰 +1.5%p/year (1억 3년 +450만원) 인상 여력.
이 보고서가 답하는 4가지
① 어떤 환경에서 NN 이 BSM 을 가장 크게 이기나? — 실데이터 + 짧은 step
② Step 단축은 무조건 좋은가? — NO (GBM 환경에선 오히려 NN 패배)
③ NN 의 진짜 가치는? — BSM 정규분포 가정이 깨지는 환경
④ 실무 의미는? — ELS 쿠폰 +1.5%p/year, 한화 5조 발행 시 P&L 임팩트 수백억

3. 발견 1 — Step 단축 효과는 환경에 따라 정반대

GBM 환경 (BSM 가정 만족) 과 Jump 환경 (BSM 가정 깨짐) 에서 step 단축의 결과가 정확히 정반대로 나옴.

StepGBM 환경 NN 개선Jump 환경 NN 개선

8시간−16.6%+6.6%
4시간−13.4%+17.4%
1시간−26.7%+22.8%
10분(미실험, 추정 −30%)+29.1%
해석: GBM 환경에선 BSM 도 step 단축 혜택을 똑같이 받음 (정규분포 가정이 맞으니까). Jump 환경에선 BSM 이 jump 못 잡고 누적 TC 만 폭증 → NN 의 적응적 헤지가 갭을 벌림. 실시장은 후자에 가까우므로 (kurt 17~29) step 단축은 실무에서 의미 있음.

4. 발견 2 — 실데이터 + 짧은 step 의 시너지

Step 단축 만으로도 NN 우위가 확대되지만, 실데이터 적용 시 fat-tail 노출이 더 강해져 추가 시너지 발생.

왜 intraday 가 fat-tail 더 강한가? 분봉 단위 spike (장 시작/마감 시간, 뉴스 직후) 가 일별로 평균화되면 사라짐. SPY 일별 kurt=17.79 도 정규분포(=3) 의 6배지만, 15분봉 kurt=29.01 은 10배. → 분봉 단위에서 BSM 정규분포 가정이 더 깨짐 → NN 우위 확대

7. 정직한 한계 — 면접에서 먼저 인정해야 할 5가지

한계영향완화 방법
1. 두 모델 모두 mean PnL 손실 NN net = premium 2.06 + mean −3.33 = −1.27 (BSM 은 −1.96). NN 이 덜 망하지만 둘 다 흑자 아님 실 spread (1-3bps) 모델로 교체 시 net 흑자 가능
2. TC=10bps 단순 가정 실 spread + impact 모델이면 결과 달라질 수 있음 order book 기반 TC 모델 + size-aware NN
3. 데이터 60일 (intraday) 특정 regime 일 수 있음. 일반화 검증 부족 polygon 등 유료 데이터 (월 $200+) 또는 walk-forward
4. 학습 100 epoch 중단 Loss 5.0 부근 진동, 더 학습 가능 200-300 epoch + GPU
5. 단일 옵션, 30일 만기 실 ELS 는 path-dependent (KO/KI), 3년 만기, basket 다차원 state + 경로 의존성 추가 모델
면접 답변 권장: "현재 결과는 PoC 단계. 실거래 도입은 위 5개 갭 R&D 추가 필요. 단 step 단축 효과 (+14% → +44%) 와 실데이터 검증 (+31% → +44%) 은 robust 한 발견." 먼저 한계 인정하면 신뢰감 ↑.

8. 비전공자 TL;DR

  • 한 줄: 6가지 실험 끝에 "SPY 실데이터 + 15분 헤지" 가 BSM 교과서 헤지의 꼬리 위험을 절반 가까이 줄임 (9.11 → 5.04).
  • 왜 강한가: 실시장은 정규분포 가정 안 맞음 (분봉 fat-tail kurt=29). BSM 은 무지성, NN 은 적응형. 짧은 step 일수록 갭 확대.
  • 실무 의미: ELS 쿠폰 +1.5%p/year 인상 가능. 1억 3년 = 450만원, 한화 5조 발행 = P&L 수백억.
  • 한계: 학술 PoC 수준. 실거래는 호가 모델 + 인프라 + paper trading 6개월 추가 필요.
  • 면접 한 방: "PPO 5번 실패 → Buehler 직접 구현 → GBM 합성 → 실데이터 → intraday step → 6개 시나리오 비교 → 최종 +44.6% 달성" 의 narrative.

10. 용어 정리집

용어한 줄 설명본문에서의 역할
CVaR@5% "가장 나쁜 5% 시나리오" 의 평균 손실 모든 비교의 핵심 지표 (낮을수록 좋음)
BSM Δ (델타) Black-Scholes-Merton 공식이 알려주는 "지금 보유해야 할 주식 수량" 비교 baseline. 정규분포 가정 한계가 본문 핵심
Buehler 2019 PG-on-CVaR NN 으로 헤지 정책 학습, CVaR loss 에 직접 backward 우리 알고리즘. PPO 와 다름
Step (n_steps) 만기 동안 헤지 비율을 몇 번 갱신할지 1day(30) ~ 15min(2880). 단축이 본 보고서 주제
TC (Transaction Cost) 거래 시 드는 수수료/스프레드 비용 (proportional 가정) 30bps(daily) / 10bps(intraday). 누적 시 핵심 영향
Kurtosis (첨도) 분포 꼬리의 두께. 정규분포=3, 클수록 fat-tail SPY daily=17.8, 15min=29 → BSM 가정 깨짐
Jump (Merton jump-diffusion) 주가가 갑자기 점프하는 비정형 변동 BSM 정규분포 가정이 못 잡는 영역
Block bootstrap 실데이터에서 N봉 묶음 단위로 random sampling vol clustering 일부 보존하며 path 생성
Differentiable simulator PyTorch tensor 로 시뮬 전체 → gradient 직통 Buehler 알고리즘의 핵심 트릭
Mean PnL 발행자가 평균적으로 얼마 벌거나 잃는지 NN 이 BSM 보다 덜 잃지만 둘 다 흑자 아님 (한계)
Turnover 만기 동안 누적 거래량 합 BSM 이 step 짧을수록 폭증 (TC 누적 원인)
ELS (Equity Linked Securities) 주가 연계 증권. 발행자가 옵션 매도자 입장 본 헤지 알고리즘의 실무 적용처
쿠폰 (Coupon) ELS 만기 시 고객이 받는 수익률 CVaR 절감 → 쿠폰 인상 여력 (실무 가치)
Capital cost (자본비용) 위험 buffer 만큼 잡아두는 자본의 기회비용 (≈10%/yr) CVaR 절감 → buffer 절감 → 쿠폰 환산 채널
OOD (Out-of-Distribution) 학습 데이터와 다른 분포에서의 평가 GBM 학습 → SPY 평가 = +17.7% (일반화 검증)
No-transaction band "델타 차이 작으면 거래 안 함" 룰 (Whalley-Wilmott 1997) 실무 표준. NN 도 학습으로 사실상 같은 룰 배움
