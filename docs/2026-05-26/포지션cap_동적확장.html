포지션 cap 동적 확장 — 강한 신호가 몰릴 때 cap 7→10 일시 우회

작성: 2026-05-26 · 작업: scripts/run_dual_paper_trading.py

한 줄 결과: 외국인+기관 동시매수 강도가 임계의 1.5배(7.5%) 이상인 후보가 free slot 보다 많을 때, 그 초과분만큼 포지션 cap 을 일시 확장 (최대 +3). 9개 단위 테스트 통과, 134개 회귀 테스트 통과. fallback 사용 중에는 cap 확장 금지로 stale 데이터의 over-trade 방지.

1. 무엇을 시도했고 왜 시도했나

1.1 배경: 오늘 cap 도달로 알파 캡처 실패

오늘(2026-05-26) 11:07 부터 외국인+기관 dual confirmation 매수 후보가 2종 떴지만, 이미 보유 7종으로 포지션 cap (7) 도달 상태였다. 즉 새 강한 신호 종목들이 코스피 +3% 랠리의 알파를 가지고 있었음에도 신규 진입이 차단됐다.

1.2 핵심 가설

"외국인+기관이 둘 다 평소 임계(5%)의 1.5배 이상 강하게 매수하는 종목"은 단순 통과 후보보다 알파가 강하다. 그 종목이 free slot 부족으로 차단되는 건 명백한 기회비용. cap 을 단기적으로 우회해도 통과 임계가 이미 높아서 false signal 위험은 제한적이다.

2.4 강도(strength) 계산

strength = min(flow_ratio, inst_ratio)   # 약한 쪽 기준 (보수적)
strong  ⇔ strength ≥ STRONG_THRESHOLD (= ENTER_THRESHOLD × 1.5 = 0.075)

"외국인 매수 비율이 높아도 기관이 약하게 동조하면" strong 아님. 양쪽 모두 7.5% 이상이어야 strong. 이중 확인의 정신을 유지하면서 강도만 한 단계 더 강하게 본다.

3. 핵심 코드

STRONG_SIGNAL_MULT = 1.5
STRONG_THRESHOLD = ENTER_THRESHOLD * STRONG_SIGNAL_MULT   # 0.075
MAX_CAP_EXTENSION = 3

def compute_effective_cap(buy_cands, positions, cfg_max_concurrent, fallback_info):
    if fallback_info is not None or buy_cands.empty:
        return cfg_max_concurrent, 0, 0

    held = set(positions.keys())
    not_held = buy_cands[~buy_cands["symbol"].isin(held)]
    if not_held.empty:
        return cfg_max_concurrent, 0, 0

    strengths = not_held[["flow_ratio", "inst_ratio"]].min(axis=1)
    strong_count = int((strengths >= STRONG_THRESHOLD).sum())

    free_slots_normal = cfg_max_concurrent - len(positions)
    if strong_count <= max(0, free_slots_normal):
        return cfg_max_concurrent, strong_count, 0

    extension = min(strong_count - max(0, free_slots_normal), MAX_CAP_EXTENSION)
    return cfg_max_concurrent + extension, strong_count, extension

5. 안전장치 (#1 fallback 과의 상호작용)

중요: fallback 사용 중에는 cap 확장 금지. 이유:
  • fallback 데이터는 어제 EOD 직전 가집계 = 시간 차 (8~24시간) 있는 stale 데이터
  • fallback 은 이미 임계값 1.5배 강화로 false signal 제한 중 → cap 확장까지 동시 발동하면 위험 증폭
  • fallback 시점은 보통 시초(09:00~09:15) = 변동성 가장 큰 구간. 그 시점에 cap 확장은 부적절
규칙: fallback_info != None 이면 cap 확장 skip → 모든 단위 테스트로 검증.

6. 효과 예측 (오늘 사례 적용)

오늘 11:07 부터 "매수 후보 2종" 이 표시됐는데, 그 후보들의 강도가 strong 임계(7.5%) 이상이었다면 cap 7→9 로 확장돼 둘 다 진입했을 것. 강도가 5~7.5% 사이의 normal 신호였다면 cap 변동 없음 (현 동작과 동일). 즉 이 fix는 "강한 신호" 에만 트리거되며 평소 cap 보수성은 유지.

7. 비전공자용 TL;DR

지금까지는 보유 종목이 7개 차면 외국인+기관 강매수 신호가 떠도 무조건 차단했다. 그런데 가끔 "남달리 강한 신호" 가 떠도 같은 룰로 막혀서 알파를 놓치는 경우가 있었다. 이번 fix는 그런 강한 신호(평소 기준의 1.5배 강도)가 있을 때만, 그 갯수만큼 한도를 임시로 풀어준다. 단 최대 3종까지(7→10). 그리고 어제 데이터 fallback 사용 중에는 이 확장 안 한다 — 신선하지 않은 데이터로 한도까지 푸는 건 위험하니까. 시나리오 9가지 단위 테스트 통과, 134개 회귀 테스트 통과.
