시초 22분 알파 복구 — 외국인+기관 추종 전략의 디스크 백업 fallback

작성: 2026-05-26 · 작업: scripts/run_dual_paper_trading.py + packages/autotrader/src/autotrader/market/foreign_inst_realtime.py

한 줄 결과: KIS 모의서버가 매일 09:00~09:15 사이 외국인+기관 가집계 데이터를 안 주는 문제를 disk 백업 기반 fallback 으로 해결. 어제 마감 직전 정상 데이터를 다음날 시초 22분 동안 임계값 1.5배 강화해 사용. 23개 단위 테스트 통과, 125개 회귀 테스트 통과.

1. 무엇을 시도했고 왜 시도했나

오늘(2026-05-26) 코스피가 +3% 가까이 상승했는데 외국인+기관 동시매수 추종 자동매매(dual confirmation) 의 portfolio 는 장중 peak에서 -3.8% 흘렸다. 시장을 못 따라간 원인을 6가지로 진단했고, 그중 가장 큰 손실 요인이 시초 22분 데이터 공백 으로 판명돼 그 fix를 먼저 진행.

1.1 배경: dual confirmation 전략이 시초에 의존하는 이유

이 전략은 외국인 매수 비율(flow_ratio = 외국인 순매수 / 거래량)과 기관 매수 비율(inst_ratio = 기관 순매수 / 거래량)이 둘 다 ±5% 이상 일 때만 진입한다. 핵심 가정: 외국인이 갭매수로 시초에 빠르게 들어오는 종목은 그날 강세가 지속되는 경향이 있다. 즉 시초 30분의 거래량 누적치가 신호의 절반 이상을 차지한다.

1.2 데이터 소스: KIS 가집계 API

가집계(假集計)는 "장중 약 1분 지연 추정치"라는 뜻으로, 영웅문 HTS의 "장중 외국인/기관 매매" 화면이 사용하는 KIS 엔드포인트 foreign-institution-total 가 시장별 매수/매도 상위 30종을 반환한다.

3. 어떻게 해결했나

3.1 핵심 아이디어: disk 백업 기반 fallback

가설: 어제 마감 직전 외국인+기관이 같이 사들이던 종목은 오늘 시초에도 그 흐름이 이어질 확률이 높다. 따라서 어제 마지막 정상 응답을 disk에 저장해 두고, 오늘 시초에 가집계가 빈 응답을 주면 그 백업을 임시로 사용한다.

3.2 구현 — 3개 컴포넌트

fetch_dual_candidates정상 응답이면 cache 저장, 빈 응답이면 cache 로드 후 임계값 1.5배 강화 적용.scripts/run_dual_paper_trading.py

5. 비전공자용 TL;DR

"외국인 사면 따라 사라" 전략의 자동매매가 매일 시초 22분 동안 데이터를 못 받아서 알파의 절반을 놓치고 있었다. 원인은 KIS 모의서버의 알려진 지연. 해결책은 단순하다 — 어제 마지막으로 받은 정상 데이터를 컴퓨터에 저장해 두고, 오늘 시초에 데이터가 안 오면 그걸 임시로 쓴다. 단 어제 데이터는 신선도가 떨어지니까 진입 기준을 1.5배 더 빡빡하게 (5% → 7.5%) 적용해서 잘못된 신호로 진입할 위험을 줄였다. 어제 데이터가 48시간 이상 됐으면 (예: 주말 끼면) 그냥 포기. 테스트 23개 + 회귀 125개 모두 통과. 내일 시초에 실측 검증.
