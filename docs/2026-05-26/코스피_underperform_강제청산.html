코스피 대비 underperform 강제 청산 — 베타 약한 종목 자동 회전

작성: 2026-05-26 · 작업: scripts/run_dual_paper_trading.py + packages/autotrader/src/autotrader/broker/kis_client.py + packages/autotrader/src/autotrader/paper/dual_state.py

한 줄 결과: 매수 시점부터 코스피 대비 5% 이상 underperform 한 보유 종목을 매 iter 자동 청산. 12개 단위 테스트 통과 (146개 회귀 모두 통과). 기존 보유 종목은 kospi_at_entry 가 없어 자동으로 skip (backward compat 유지), 새 매수부터 점진 적용.

1. 무엇이 문제였나

1.1 오늘 사례 — peak 에서 -3.8% 흘림

오늘(2026-05-26) 코스피가 +3% 정도 올랐는데 portfolio 는 장중 peak (11.40M) 에서 현재 (10.97M) 까지 -3.8% 흘렸다. cap 도달로 신규 진입은 안 됐고, 동시에 보유 7종 중 일부가 시장 대비 약세였던 게 원인.

1.2 베타 (β) 개념과 보유 종목 분포

베타의미코스피 +3% 일 때 기댓값
1.0시장과 같이 움직임+3%
0.5시장의 절반만+1.5%
1.5시장보다 1.5배 출렁+4.5%
음수시장과 반대-3%

오늘 보유 7종 평균 베타 추정 ≈ 0.85 (방어주 + 중소형주 혼재). 즉 코스피 +3% 일 때 기댓값 +2.55%. 거기에 종목별 그날 알파가 빠지면 실제는 +1~2% 수준.

1.3 dual confirmation 전략의 구조적 한계

"외국인+기관 둘 다 매수" 조건을 통과하는 종목은 자연스럽게 방어적 대형주 또는 저변동 가치주 가 많다. 양쪽이 동의하는 종목은 "꾸준히 사들이는 안정 종목" 이라 베타가 1보다 낮은 경향. 이게 alpha 측면에선 장점(누적 매수세 = 안정 상승)이지만, 시장 directional rally 의 베타는 못 잡는다.

2. 어떻게 풀었나

2.1 핵심 아이디어

relative_return = stock_return - kospi_return
                = (현재가 - 매수가) / 매수가  -  (현재코스피 - 매수시코스피) / 매수시코스피

if relative_return < -threshold (= -5%):
    강제 청산

"매수 이후 코스피보다 5% 이상 뒤처졌으면 그 자리에 더 강한 후보가 들어올 수 있게 자리 비워준다" 는 단순한 회전 룰.

2.3 매 iter 흐름 (신규)

0. 보유 잔고 sync + 현재가 평가
1. KOSPI 지수 현재가 조회 (kospi_now)          ◀ NEW
2. dual confirmation 후보 fetch (#1 fallback 포함)
3. dual sell 신호 → 매도 (기존)
4. 각 보유 종목 underperform 검사 → 강제 청산 (#5 NEW)
   - kospi_at_entry 없으면 skip (기존 보유 종목 backward compat)
   - entry_date 부터 2거래일 미만이면 skip (잡음 흡수)
   - relative_return < -5% 면 매도 주문 + state 갱신
5. cap 확장 계산 (#3) → 매수 → Position 에 kospi_now 기록

2.4 핵심 helper

UNDERPERFORM_THRESHOLD = 0.05         # 5%
UNDERPERFORM_MIN_HOLD_DAYS = 2        # 최소 2거래일 보유 후 검사

def should_force_sell_underperform(position, current_price, current_kospi,
                                     today=None, threshold=..., min_hold_days=...):
    # Skip 조건들 — 데이터 부족 / 너무 짧은 보유
    if position.kospi_at_entry is None or position.kospi_at_entry <= 0:
        return False, None
    if current_kospi <= 0 or current_price <= 0 or position.avg_entry <= 0:
        return False, None
    if _days_between(position.entry_date, today) < min_hold_days:
        return False, None

    stock_return = (current_price - position.avg_entry) / position.avg_entry
    kospi_return = (current_kospi - position.kospi_at_entry) / position.kospi_at_entry
    relative = stock_return - kospi_return
    return (relative < -threshold), relative

7. 비전공자용 TL;DR

지금까지 매수한 종목들은 외국인+기관 둘 다 매도해야 청산했는데, 그 신호가 안 떠도 코스피가 신나게 오를 때 못 따라가는 종목들이 자리만 차지하고 있었다. 이번 fix는 단순히 "매수 이후 코스피보다 5% 이상 뒤처졌으면 그 종목 강제로 팔고 자리 비운다" 룰을 추가했다. 단 매수 직후 2일 동안은 변동성 잡음일 수 있어서 검사 안 함, 코스피 가격 못 받으면 검사 안 함, 옛날에 산 종목은 매수 시점 코스피를 모르니까 검사 안 함. 새로 사는 종목부터 점진적으로 적용된다. 12개 단위 테스트 + 146개 회귀 테스트 모두 통과.
