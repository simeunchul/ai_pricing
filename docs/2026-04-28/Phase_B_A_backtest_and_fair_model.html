2. Phase B — 운영 파라미터 검증

2-1. 충격적 발견 — 1bps 단타는 수학적 손실

현재 운영 파라미터 (enter=1bps, exit=0.2bps, qty=20) 의 backtest PnL = -68,969원 (-0.69%)
  • 매매 144건 (BUY 83 / SELL 61)
  • 총 수수료/세금: 39,388원
  • 총 슬리피지: 52,516원
  • 총 비용 91,904원 > |PnL| → 비용이 수익보다 큼
  • Win rate 36.1%, Sharpe -0.036
KIS 모의투자(수수료 0)에선 안 보였던 적자가, 실 prod 비용 가정 (round-trip 4-7bps) 시 정직하게 드러남.

3-4. Hook 인터페이스 (A4) — Skeleton 만

모델이 의미 있어진 후 (walk-forward 통과) 봇에 어떻게 연결할지 디자인:

class FairValuePricer:
    """학습된 LightGBM 모델 + ETL 을 production runner 와 연결."""

    def maybe_refresh(self, now, tick_log_path) -> bool:
        """N분마다 ETL 재실행 + 모델 추론."""
        ...

    def fair_dev(self, symbol, current_price) -> float:
        """모델이 예측한 next-bucket return 을 dev 형태로 변환."""
        return -self._fair_returns.get(symbol, 0.0)


# 새 strategy 메서드 (decide_aggressive 위에 얹음)
def decide_with_fair(self, dev_basket, fair_dev,
                     basket_weight=0.5, fair_weight=0.5):
    combined_dev = basket_weight * dev_basket + fair_weight * fair_dev
    return self.decide_aggressive(combined_dev)

실제 prod 연결 보류 — 모델이 baseline 못 이김. 데이터 1주 누적 후 walk-forward 통과 시 연결.

5. 비전공자용 요약 (TL;DR)

  • 봇이 모의투자에서 "수익" 처럼 보였던 건 수수료가 0이라서. 실제 KIS 수수료(0.015%) 적용하면 1bps 단타는 매매할수록 손해.
  • 96가지 파라미터 조합으로 brute-force 찾은 최적: 10bps에서 진입, 50주씩 매매, 1bps 도달하면 청산. 이걸로 +0.24% 나왔지만 1일 데이터라 운빨일 수 있음.
  • 뉴스 + 종목 정보 → AI 모델 (LightGBM) 로 적정가 예측 인프라 구축 완료. 단 1일치 322 샘플로는 모델이 외워버려서 (train R² 0.89, test -0.11) 실전엔 못 씀. 1주~1개월 데이터 모은 뒤 재학습.
  • 한국 KOSPI 200 ETF 시장은 너무 효율적이라 차익 알파 자체가 작음. 진짜 수익을 키우려면 모델 정확도 + 비용 협상 + 사이즈 관리 + 다른 알파 (장투, 옵션 등) 종합 필요.
