ETF iNAV 차익전략 — 공격적 사이징 + 인버스 ETF 합성 short

2026-04-28 · packages/autotrader · 작성: Claude (자동 생성 보고서)

한 줄 결과. ETF 가격 vs iNAV 괴리(deviation)에 비례해 매매 수량을 5/10/15… 주로 키우고 (기존 1주 고정), 개인이 직접 공매도가 막힌 상황을 우회하기 위해 KOSPI 200 인버스 ETF (252670) 매수로 합성 short 포지션을 잡도록 라우팅을 추가.
테스트 24/24 통과.

1. 무엇을 시도했는가 — 배경 + 접근

배경. 자동매매 봇이 ETF 1주 단위로만 사고 팔고 있었음. 한국 KOSPI 200 ETF (KODEX 200, 069500)가 iNAV 대비 30bps(0.3%) 이상 괴리되면 BUY/SELL 시그널을 내지만 항상 1주만 거래 → 큰 괴리에서도 작은 포지션. 사용자 요청: "괴리가 크면 더 많이 사라. 그리고 공매도 못 한다고 했지만 어떻게든 short도 가능하게."

접근. 두 가지를 분리해서 다뤘다.

  1. 사이즈 사다리(qty ladder) — 30bps 단위로 5주씩 누적. 30bps→5주, 60bps→10주, 90bps→15주 … 최대 50주(=10단계)까지 cap. 기존 1주의 5배 공격성.
  2. 인버스 ETF 라우팅 — ETF가 비쌀 때(deviation 양수) 일반 SELL 대신 KODEX 200 인버스 (252670)를 BUY. 인버스 ETF는 KOSPI 200을 음의 베타로 추종하므로 매수 = 사실상 short.

2. 무엇이 한계였나 — 변경 전 상태

구분변경 전이유
매매 수량항상 1주MVP 단순화 (qty=1 하드코딩)
최대 포지션±10주위험 한도 보수적 설정
SELL 처리 (flat 상태)position을 -1로 떨어뜨리지만 실제 주문 안 들어감개인 계정에선 공매도 불가
피라미딩(추가 진입)없음 — 한 번에 1주 사고 끝고정 사이즈라 의미 없음
특히 문제였던 부분. decide()가 음수 position을 반환할 수 있는 코드 경로가 있었지만, 실제 KIS 모의투자 API에선 short 주문이 거부되어 "신호는 SELL인데 체결은 안 되는" 데드 코드 상태였다. 이번 PR에서 인버스 ETF 라우팅으로 그 갭을 메움.

이전 의사결정 흐름 (1주 고정)

deviation 측정 │ ├─ dev < -30bps ──► BUY 1주 (069500) │ ├─ dev > +30bps ──► SELL 1주 (체결 안 됨, 보유 0이면) │ └─ |dev| < 5bps ──► position 청산 (1주)

3. 어떻게 해결했는가 — 코드

3-1. 사이즈 사다리

def _qty_for(self, deviation: float) -> int:
    # 1e-9 epsilon: 0.009 / 0.003 → IEEE-754에서 2.9999... 로 떨어져
    # int()가 3을 2로 잘라먹는 문제 흡수
    steps = int(abs(deviation) / self.enter_threshold + 1e-9)
    if steps <= 0:
        return 0
    return min(steps * self.qty_per_step, self.max_position)

3-2. 새 의사결정 함수 — decide_aggressive

(signal, qty, use_inverse) 3-튜플을 반환. use_inverse=True면 runner가 인버스 ETF 종목코드로 주문을 라우팅한다.

def decide_aggressive(self, deviation: float) -> tuple[Signal, int, bool]:
    target_qty = self._qty_for(deviation)

    if self.position > 0:               # 기존 long ETF
        if deviation > -self.exit_threshold:
            return Signal.SELL, self.position, False    # 전량 청산
        if deviation < -self.enter_threshold:
            extra = min(max(0, target_qty - self.position),
                        self.max_position - self.position)
            if extra > 0:
                return Signal.BUY, extra, False           # 피라미드
        return Signal.HOLD, 0, False

    if self.inverse_position > 0:        # 기존 합성 short
        if deviation < self.exit_threshold:
            return Signal.SELL, self.inverse_position, True
        if deviation > self.enter_threshold:
            extra = min(max(0, target_qty - self.inverse_position),
                        self.max_position - self.inverse_position)
            if extra > 0:
                return Signal.BUY, extra, True
        return Signal.HOLD, 0, False

    # flat — 신규 진입
    if deviation < -self.enter_threshold:
        return Signal.BUY, target_qty, False             # 069500 매수
    if deviation > self.enter_threshold:
        return Signal.BUY, target_qty, True              # 252670 매수 = synthetic short
    return Signal.HOLD, 0, False

3-3. runner 라우팅

INVERSE_MAP = {
    "069500": "252670",   # KODEX 200 → KODEX 200 인버스
}

# 매 틱:
signal, qty, use_inverse = strategy.decide_aggressive(dev)
if signal != Signal.HOLD and qty > 0:
    target_symbol = inverse_symbol if use_inverse else symbol
    client.order(target_symbol, qty=qty, side=signal.value.lower())
    strategy.apply_aggressive(signal, qty, use_inverse)

4. 최종 결과 — 차트와 비교표

4-1. 사다리 곡선 (변경 전 vs 변경 후)

x축은 절댓값 deviation (bps) — 양수면 ETF가 비싸 인버스 매수, 음수면 ETF가 싸 ETF 매수. y축은 한 번의 의사결정에서 발주되는 수량. 기존 빨간 선은 30bps 이상에서 항상 1주. 파란 신규 사다리는 30bps마다 5주씩 가산, 300bps에서 50주에 도달 후 cap.

4-2. 의사결정 흐름 (신규)

iNAV 측정 │ ▼ deviation = (ETF − iNAV) / iNAV │ ├─ position(ETF) > 0 ────┐ │ dev > -5bps ──► SELL position 전량 (069500) │ dev < -30bps ──► BUY 추가분 (피라미드, cap 50) │ ├─ inverse_position > 0 ─┐ │ dev < +5bps ──► SELL inverse 전량 (252670) │ dev > +30bps ──► BUY 추가분 (피라미드, cap 50) │ └─ flat ─────────────────┐ dev < -30bps ──► BUY ETF (069500), qty = ladder dev > +30bps ──► BUY 인버스 (252670), qty = ladder ← 합성 short 그 외 ──► HOLD

5. 위험 경고 — 반드시 읽을 것

실전에서 마이너스 가능성이 농후한 구간이 있다.
  • 30bps 진입 임계값은 KIS 모의투자(수수료 0)에선 양의 기대값을 줄 수 있지만, 실계좌에선 ETF 거래수수료 + 매도 시 거래세 (ETF는 면제, 인버스 ETF도 면제) + 호가 슬리피지를 합치면 30bps로는 거의 break-even 수준이다.
  • iNAV 자체가 5종목 외삽 모델이라 추적 오차(tracking error)가 있다. 진짜 괴리가 아닌 모델 노이즈를 보고 거래할 위험.
  • 인버스 ETF는 일별 리밸런싱 구조라 며칠 보유 시 음의 복리(negative compounding)가 누적된다. 이 전략은 인트라데이 청산이 전제.
  • 피라미딩이 들어가서 deviation이 더 벌어지는 동안 포지션이 누적된다. 평균회귀(mean reversion) 가정이 깨지면(예: 시장 충격 후 미수렴) 손실이 비례 확대.
권장. 처음에는 KIS 모의투자에서 며칠 돌려 PnL 분포를 확인하고, 실거래 전환 시엔 max_position을 50 → 10으로 일시 축소해서 시작.

6. 비전공자용 요약 (TL;DR)

"ETF가 진짜 가치보다 0.3% 싸게 거래되면 사고, 0.3% 비싸게 거래되면 (직접 못 파니까) 인버스 ETF를 사서 사실상 공매도 효과를 낸다. 차이가 클수록 더 많이 산다."

  • 기존: 차이가 0.3%든 1%든 항상 1주만 사고 팔았음 → 너무 소극적.
  • 신규: 0.3%마다 5주씩, 최대 50주까지 비례해서 키움. 차이가 더 벌어지면 추가 매수도 함.
  • 한국 개인은 ETF 공매도가 안 됨 → "내려가는 데 베팅하는 ETF (인버스)"를 사면 같은 효과.
