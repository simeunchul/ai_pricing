2. 외국인+기관 동방향 신호 — 메커니즘

로직

flow_ratio = 외국인 순매수 / 거래량
inst_ratio = 기관 순매수 / 거래량

if 둘 다 +threshold 초과:    매수 신호
if 둘 다 -threshold 미만:    매도 신호 (보유 시)
if 부호 다름 (+ vs -):      HOLD (의견 충돌 → 신호 cancel)
if 한 쪽이 약함:             HOLD (노이즈)

매매량 = round(min(|flow|, |inst|) × sizing_factor)
        = 더 약한 쪽 기준 (보수적 confirmation)

왜 이게 단일 외국인 신호보다 좋은가

SNR (신호대잡음비) 폭증 — 외국인 + 기관 둘 다 매수 = 시장 정보 우위 그룹 둘이 같은 의견 = 진짜 신호. 한쪽만 매수하면 (예: 외국인 + / 기관 -) 의견 충돌 = 신호 노이즈. 두 그룹 합의 필요 → 진입 빈도 ↓ 정확도 ↑.

4. 실시간 KIS wrapper 아키텍처

구현 layout

                          │
                          │ /uapi/domestic-stock/v1/quotations/foreign-institution-total
                          │ TR_ID = FHPTJ04400000
                          │ ~1분 지연 추정치
                          ▼
   ┌─────────────────────────────────────────┐
   │ KISClient.foreign_institution_total()   │  broker/kis_client.py
   │ — token 재사용, env=vts/prod 둘 다 가능   │

                  │
                  ▼
   ┌─────────────────────────────────────────┐
   │ parse_foreign_institution_response()    │  market/foreign_inst_realtime.py
   │ — JSON output[] → DataFrame             │
   │ — 종목 코드/이름/외국인qty/기관qty 등     │
   └──────────────┬──────────────────────────┘
                  │
                  ▼
   ┌─────────────────────────────────────────┐
   │ compute_flow_ratios(df, daily_volumes)  │
   │ — flow_ratio = foreign_qty / volume     │
   │ — inst_ratio = inst_qty / volume        │
   └──────────────┬──────────────────────────┘
                  │
                  ▼
   ┌─────────────────────────────────────────┐
   │ ForeignInstFlowFollow.decide()          │  strategies/foreign_inst_flow.py

   │   → BUY / SELL / HOLD signal            │
   └──────────────┬──────────────────────────┘
                  │
                  ▼
   ┌─────────────────────────────────────────┐
   │ KISClient.order() (dry_run 검증)        │
   └─────────────────────────────────────────┘

8. 용어 정리집 (이번 보고서 신규)

용어한 줄 설명본문에서의 역할
Dual Confirmation (이중 확증) 두 개 이상의 독립적 신호 source 가 같은 방향을 가리킬 때만 진입. 외국인 + 기관 둘 다 매수 → 진입. 한 쪽만 매수면 노이즈로 무시
SNR (Signal-to-Noise Ratio) 진짜 신호 / 노이즈 비율. 클수록 정확. 단독 외국인 SNR ~30% / 외국인+기관 ~70% — 신호 정확도 폭증
장중 가집계 (Intraday Estimate) 장중 거래 데이터 기반 외국인/기관 매매 추정. EOD 정산 전 임시 집계. 영웅문 화면이 보여주는 실시간 외국인 데이터 = 이것
FHPTJ04400000 KIS API foreign-institution-total endpoint 의 TR_ID. 우리 wrapper 에서 사용. vts/prod 양쪽 가능
signal_keys 백테스트가 strategy 에 넘기는 신호 종류 tuple. 다중 신호 strategy 지원 인터페이스. ForeignInstFlowFollow 는 ("flow_ratio", "inst_ratio")
RealtimeFlowCache 분 단위 갱신 in-memory 캐시. KIS 호출 빈도 제한. 매번 API 호출 X, 60초마다 갱신해서 호출량 절감
compute_flow_ratios KIS 응답 + 거래량 데이터 → flow_ratio / inst_ratio 계산. strategy 가 받는 input 형식으로 변환하는 어댑터
vts vs prod KIS 모의투자 (vts) / 실계좌 (prod) 환경 구분. 시세조회는 둘 다 가능, 실주문은 prod 만 (dry_run=false 추가 필요)
