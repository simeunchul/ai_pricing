Phase A 검증 — Fair-value ML 모델 negative finding

2026-04-28 · ai_pricing/autotrader · Phase A 의 정직한 마무리

한 줄 결과. Phase A2-D 에서 R² +0.037 으로 "약한 알파" 처럼 보였던 모델을 사용자 의심으로 검증한 결과, walk-forward 에선 R² −0.025 ~ −0.355 으로 baseline 못 이김. 데이터를 30일 → 6개월 + DART 공시 로 늘려도 결과 동일 (R² 더 음수). 현재 features 로는 fundamental no-signal 결론. 모델 prod 연결 영구 보류. 이 검증이 거짓 알파를 prod 에 들이는 사고를 막았다 — 가장 큰 가치.

1. 무엇을 시도했는가 — 검증의 동기

이전 보고서 (Phase_A2_D_pre_news_features.html) 에서 LightGBM 모델이 Test R² +0.037, baseline 대비 RMSE 4.5% 개선 이라는 "약하지만 양수" 결과를 얻음. 이걸로 봇 hook 인터페이스까지 구축하고 prod 연결 단계.

사용자 핵심 질문:

"근데 이게 뉴스 이후의 30분뒤 시장가격을 본거잖음? 근데 이걸로 어떻게 추론함? 뉴스야 말로 진짜 랜덤인데"

이 질문이 정확히 검증의 출발점. R² +0.037 은 정말 정보적 가치가 있나, 아니면 random split 의 우연인가? 시계열 데이터에선 random split = 거짓말 가능성 매우 큼.

핵심 교훈 — Random split 의 함정

시계열 데이터에서 random train/test split 은 거짓말한다.
데이터가 시간 순으로 섞이면 train 에 미래 정보가 들어가서 test 정확도가 부풀려짐. 반드시 walk-forward (시간 순 분할) 로 검증해야 진짜 일반화 능력 확인 가능.

3. 2차 검증 — 데이터 더 모아도 같음

1차 결과를 받아들이지 못하고 — "데이터가 부족해서 그런가? 6개월치 + DART 공시 까지 합치면 다를까?" 시도. 결과는 더 명확하게 부정적.

4. 정직한 결론

가설결과

왜 안 되는가:
1. 한국 주식시장이 short-term 에서 매우 efficient — pre-event momentum 도 이미 가격에 반영됨
2. Retail 5분 lag = HFT 가 이미 잡은 알파
3. DART 공시가 신뢰도 높지만 시각이 정확치 않아 (rcept_dt = 일자만) 효과 X
4. 키워드 sentiment lexicon 은 너무 sparse — 실제 뉴스 의미 파악 X
5. 12 features 만으론 1시간 후 stock return 의 분산을 설명할 수 없음 (정보량 부족)

5. 이 검증의 진짜 가치

거짓 알파를 prod 에 들이지 않은 것이 가장 큰 가치.
R² +0.037 만 보고 봇에 hook 했다면, 모델이 baseline 보다 나쁜 시그널을 봇 결정에 30% 가중해서 손실 발생했을 것. 사용자가 의심하지 않았다면 그대로 진행됐을 것.

Quant 학습의 가장 중요한 교훈 3가지를 명확히 확인:
  1. 시계열 데이터에서 random train/test split = 거짓말
  2. R² 의 작은 양수도 walk-forward 거치면 음수 가능
  3. "데이터 더 모으면 될 것" 도 가설일 뿐, 검증해야 함

6. 비전공자용 요약 (TL;DR)

  • 모델이 학습 데이터에서 baseline 약간 이긴다고 봤는데 (R² +0.037), 그게 학습/테스트 데이터를 시간 순서 무시하고 섞어서 생긴 거짓 양성이었음.
  • 제대로 시간 순서대로 (과거로 학습, 미래로 테스트) 검증하니 모델이 baseline (= 항상 0% 예측) 보다 나쁨.
  • "데이터 부족 때문일까?" 6개월치 + 정부 공시 데이터 까지 모아도 결과 동일. 더 나빠짐.
  • 결론: 현재 features (사전 가격 움직임, 시간, 종목, 단순 키워드 감성) 로는 1시간 후 주가 예측 불가능. 한국 주식시장이 너무 efficient.
  • 봇은 fair-value 모델 hook 안 함. 차익 봇만 단독 운영 (Phase B 의 sweet spot 파라미터).
  • 가장 큰 수확은 거짓 알파를 prod 에 안 들임 — 사용자가 의심한 덕분.

7. 다음 단계 (현실적 우선순위)

  1. 차익 봇 sweet spot 일주일 검증 — Phase B 의 enter=10/exit=1/qty=50 파라미터로 운영, 매일 PnL 누적
  2. 장투 시스템 설계 — 자산배분 + DCA + 리밸런싱. retail 강점 활용 영역 (이전 대화에서 거론)
  3. 옵션 / ELS 가격책정 강화 — 이미 codebase 에 있는 영역, 직무 관련성 높음
  4. Fair-value ML 모델은 영구 보류 — 다음 시도 시엔 sentence embedding (KR-SBERT) 또는 다른 features (펀더멘털, 호가) 부터. 그 전엔 안 함.
