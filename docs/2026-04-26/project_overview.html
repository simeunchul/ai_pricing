1. 이 프로젝트가 정확히 뭘 하나

핵심 한 줄 — 옵션·ELS 같은 파생상품의 "공정 가격" 을 5 가지 서로 다른 방식으로 계산하고, 그 결과를 동일한 시장 시나리오에 부어서 어느 방식이 더 정확한지 / 더 빠른지 / 거래비용 환경에서 더 잘 헤지하는지를 비교한다.

그 위에 다음 두 축을 더 얹었다:

  • 실거래 시뮬 — 한국투자증권 Open API (KIS Developers) 로 모의투자 자동매매 (ETF iNAV 괴리 전략).
  • 고성능 가속 — 가장 무거운 Monte Carlo 시뮬을 numpy → C++ (pybind11+OpenMP) 로 옮겨 14.8× 가속.
핵심 차별화 — 보통의 퀀트 토이 프로젝트는 "BSM 식 한 번 짜고 끝" 이지만, 이 저장소는 동일 옵션을 5가지 방법으로 가격 매기고 비교하는 실험 프레임워크 자체가 산출물. 마지막에는 그것들을 묶어서 scripts/desk_day.py 라는 "한화 ELS 데스크의 하루" 시뮬레이션으로 통합 → 단일 실행으로 전 Layer 가 시간 순서대로 돌아간다.

4. 5 Layer 의 역할 (각 1 단락)

Layer역할한 문장 설명대표 산출물 / 검증
A Classical Pricing 이론서대로 BSM·Binomial·MC·Greeks·IV·Heston·ELS step-down 을 직접 구현. 다른 모든 Layer 의 ground truth. 한화 ELS 8286호 (3자산, 3Y, 11.31%) +2.17% 재가격 (목표 ±3%)
B1 NN Pricer (S,K,T,r,q,σ) 6개 입력 → 옵션 가격을 신경망으로 직접 매핑. exotic/ELS 의 MC 비용(초) 을 추론 (ms) 으로. ATM IV 오차 0.548 vp, BSM 대비 추론 20× 가속
B2 Deep Calibration 시장 IV surface → Heston 5 파라미터 역매핑을 1초 내. semi-analytic 최적화 대신 NN gradient descent. IV RMSE 0.495 vp, semi-analytic 35s vs 1.36s (26×)
B3 News-IV 뉴스·매크로 이벤트 → 분류 → IV shift 적용 → 재가격. rule / FinBERT / Claude API 3 backend. FOMC+CPI N=46 backtest 34.8% (FAIL) → vol-crush 진단 → v2 surprise-aware 54.8%
B4 Deep Hedging 거래비용 환경에서 BSM Δ 헤지보다 CVaR 를 줄이는 정책을 RL 로 학습. PPO 5번 실패 → Buehler 직접 구현 PG-on-CVaR. TC=30bps 에서 BSM 대비 CVaR +24.5%, 실데이터 SPY +31.3% PASS
C Comparison 5 method 를 동일 옵션·동일 경로에서 돌려 mean_err / IV err / CVaR / Sharpe / 추론속도 비교. data/all_methods_pricing.csv, data/all_methods_hedging.csv
D Auto-Trading KIS Developers REST API 로 ETF iNAV 괴리 매매. 3-단 risk guard (포지션 20% / 일일 −1.5% / 장 open/close 10분 차단). DRY_RUN 20초 스모크 통과, Avellaneda-Stoikov LP 6개월 백테스트
E C++ fastmc 가장 무거운 1M paths × 252 steps MC 를 pybind11 + OpenMP 로. numpy fallback 자동. numpy 1.98s → C++ 0.13s (14.8×), native 활성 확인
compliance 패키지 (cross-cutting) — 모든 의사결정 (가격, 편차, 매매)을 audit_log.jsonl 에 누적, 임계치 (5%) 초과 시 DeviationMonitor 가 잡고 HITL (human-in-the-loop) 게이트 가 발동. AI 기본법 자발 대응 + 한화 RM 부서 보고용. desk_day 한 번 실행에 23 건 기록.

8. 비전공자용 TL;DR

  1. 이 저장소는 "옵션 가격 1 개를 5 가지 방법으로 매기고 비교" 하는 실험실. 그 위에 자동매매 + C++ 가속 + AI 기본법 대응 모듈을 얹었다.
  2. 5 가지 방법 = (A) 교과서 공식, (B1) 신경망, (B2) 신경망 역매핑, (B3) 뉴스 반영, (B4) 강화학습 헤지.
  3. 오늘 (2026-04-26) 모든 단위 테스트 37/37 통과, desk_day.py 통합 시나리오 끝까지 정상 종료, 23 건 의사결정 audit log 기록 으로 end-to-end 동작 확인.
  4. 가장 인상적인 결과 — Buehler 강화학습 헤지가 BSM Δ 헤지보다 거래비용 환경에서 위험을 24.5% 줄임 (실데이터로는 31.3%).
  5. 가장 정직한 실패 — News-IV 가설이 매크로 발표일 N=46 백테스트에서 부호 일치율 34.8% 로 깨짐. 진단 (vol-crush) 후 v2 surprise-aware 로 54.8% 회복.
  6. "제가 짠 게 진짜로 돈을 벌어요" 가 아니라 "제가 만든 비교 프레임워크가 어느 방법이 어떤 조건에서 잘 되는지 정직하게 가립니다" 가 이 저장소의 메시지.

10. 용어 정리집

용어한 줄 설명본문에서의 역할
옵션 (Option) 미래 시점 T 에 기초자산 가격이 K 보다 크면 차액을 받는 (call) 또는 작으면 받는 (put) 계약 Layer A~B 모든 가격 모델의 입력 단위
BSM (Black-Scholes-Merton) 1973년 Black/Scholes/Merton 의 옵션 가격 닫힌 형식 공식 — 입력 6개 (S,K,T,r,q,σ) 만으로 가격 산출 Layer A 의 기준선이자 다른 모든 Layer 의 비교 baseline
IV (Implied Volatility) "시장 가격을 BSM 식에 거꾸로 넣었을 때 나오는 σ" — 시장이 느끼는 불확실성 레벨. 단위 vp = vol point = 1 σ × 1%p B2 가 캘리브레이션 대상, B3 가 조정 대상, NN Pricer 평가 단위
Δ (Delta) 기초자산 1 원 변할 때 옵션이 몇 원 변하나 (∂C/∂S). 헤지 비율로 사용 Layer A Greeks 산출, B4 의 baseline 헤지 전략 (BSM Δ-hedge)
CVaR@5% "최악의 5% 손실들의 평균" — 단순 VaR 보다 꼬리위험 측정에 강함 Layer B4 Deep Hedging 의 최적화 목적함수 + 비교 지표
ELS step-down 3년 만기 동안 6개월마다 조기상환 기회 (94/89/89/84/84/79 % 등 단계 하강), KI 만나면 원금손실 가능한 한국 대표 파생상품 한화투자증권의 핵심 상품, Layer A 에서 MC 로 가격, B4 에서 헤지
