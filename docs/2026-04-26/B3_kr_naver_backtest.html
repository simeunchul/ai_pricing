B3 한국 시장 Naver 뉴스 백테스트 — Negative Result + 진단

2026-04-26 · Naver 검색 API + KOSPI 시총 상위 10 종목 + KODEX 200 ETF · 9,291 헤드라인 → 825 분류 → 612 정렬 → 3개 가설 모두 FAIL. 의미 있는 negative result + 4가지 개선 방향.

한 줄 결과 — 한국 시장 풀 파이프 (Naver 뉴스 → 한글 분류기 → KODEX 200 next-day return) 동작 검증 ✓. 가설 자체는 약함: baseline mean abs return 2.96% 가 너무 큼 + event 가 매일 발생 → 신호 안 나옴. 4가지 개선 경로 (magnitude scoring / 키워드 정밀화 / IV proxy 변경 / event dedup) 진단.

1. 무엇을 시도했는지

배경

어제까지 Layer B3 의 한계는 "한국 뉴스 → 한국 IV 풀 파이프 미검증" 이었음. Naver Developers Search API 키 발급 후 정량 백테스트 진행.

접근법

  1. scripts/fetch_naver_news.py: KOSPI 시총 상위 10 종목 × 30일 헤드라인 수집 → 9,291건 cache
  2. scripts/b3_backtest_kr.py: classify_rule (한글 키워드) → event 분류
  3. 이벤트일 D 의 다음 영업일 KODEX 200 (069500) 일별 return 측정
  4. 3가지 가설 검증:
    1. negative event → 다음날 return < 0 부호 일치율
    2. event 다음날 mean |return| vs baseline mean |return| 비율
    3. top 20% magnitude event 만 본 ratio

왜 KODEX 200 (V-KOSPI 아님)

V-KOSPI 200 (한국 VIX 등가) 은 KRX 지수 함수가 인증 차단으로 접근 불가 (KRX 로그인 실패: KRX_ID 또는 KRX_PW 환경 변수가 설정되지 않았습니다). 종목 / ETF OHLCV 는 작동 → KODEX 200 일별 return 의 절대값을 realized vol proxy 로 사용. IV 직접 측정 아닌 사후 realized vol → 신호-노이즈 비율 낮은 한계 인지.

3.3 진단 — 4가지 실패 원인

#원인증거
1 Event 가 매일 발생 → 신호 vs 비신호 구분 무의미 825 event / 30일 = 일평균 27.5건. 60 영업일 거의 다 event 일.
baseline 자체가 "event 가 거의 매일 있는 평균" 임.
2 키워드 정밀도 약함 (특히 macro_shock 311건) "금리" 단어만 들어가도 macro_shock. 단순 언급 vs 실제 충격 구분 안 됨.
정확히는 "rate hike", "fomc", "geopolitical" 등이 회사 이름 옆에 있어도 매칭.
3 Baseline 2.96% 비정상적으로 큼 KODEX 200 일별 절대수익률 평균 2.96%? 정상은 0.5~1% 수준.
KRX 인증 차단으로 일부 데이터 누락 / 잘못 정렬 가능성.
또는 60일 중 큰 변동일이 다수 (시장 stress 기간).
4 Realized vol proxy 의 신호-노이즈 비율 낮음 IV 직접 측정 아닌 next-day |return| 사용.
일별 noise 가 event 신호보다 큼.
V-KOSPI 직접 받았다면 더 명확했을 수도.

4. 어떻게 해결할 수 있나 (다음 단계)

#개선 방향예상 효과구현 난이도
1 Magnitude scoring — 키워드별 중요도 가중. "금리 인상" + "Fed" + "긴급" 같이 여러 시그널 누적 시만 high event. 대 (event 정밀도 ↑) 중 (~3시간)
2 Event dedup + 일별 aggregation. 같은 날 매크로 27건 있으면 1개 event 로 합산. event-day vs non-event-day 구분 의미 살림. 대 소 (~1시간)
3 FinBERT (snunlp/KR-FinBert-SC) 사용. rule 키워드 대신 NLP 분류. precision ↑. 중 중 (~4시간, 모델 download)
4 V-KOSPI 200 우회 — KRX_ID 발급 받거나, yfinance 의 EWY (iShares Korea ETF) 옵션 chain 으로 한국 IV proxy 측정. 중 (정확한 IV) 중
5 이벤트 surprise 측정 — 어닝 발표 자체가 아니라 "예상 vs 실제" gap 으로 magnitude 정의 (production_gap_closure.html v2 패턴). 대 (가설 핵심) 대 (외부 컨센서스 데이터 필요)
가장 가성비 큰 다음 단계 — #2 (event dedup) + #1 (magnitude scoring) 조합. 같은 날 27건 발생을 1개 weighted event 로 → "큰 event 일" 만 baseline 과 비교. 현재 baseline 이 "거의 매일 event 있는 평균" 이라 가설 약하게 나오는 게 핵심 문제.

5. 의미 — 면접 자리에서 어떻게 말할까

예상 질문: "B3 News-IV 가 한국 시장에서 동작하나요?"

답안:
"두 layer 로 나눠 답: (1) Pipeline 동작 검증은 완료. Naver 검색 API 로 KOSPI 시총 상위 10종목 30일 9,291 헤드라인 수집, 한글 rule classifier 로 825건 event 분류 (8.9% recall). (2) 가설 정량 검증은 negative result. Event 다음날 mean |return| 이 baseline 대비 0.39× — 오히려 vol crush 효과. 진단: event 가 일평균 27건 발생해서 baseline 자체가 'event 가 매일 있는 평균' 이라 signal vs noise 구분 안 됨. 다음 단계는 event dedup + magnitude scoring 으로 '진짜 큰 event 일' 만 추리는 방향. 단순 키워드 한계 명확히 진단함."
