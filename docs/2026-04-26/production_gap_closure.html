6. P5 — fastmc production scale 벤치마크

시나리오

실 데스크 야간 re-pricing 부하: 보유 옵션 N=1k~100k × 10k paths × 63 steps (3M 만기). 기존 14.8× 결과는 단일 옵션 1M paths 라 production 부하 대표 못 함.

8. 비전공자용 요약 (TL;DR)

  1. 지난 세션에 "실무 시스템 가능?" 질문에 너무 빨리 "멀음" 이라고 답했는데, 실제로 표 8 항목을 다시 보니 5개는 개인 환경에서 시간만 들이면 즉시 가능했다.
  2. B3 (뉴스→IV): 캘린더를 2년치 46건 → 10년치 208건으로 늘리고, 가설을 "이벤트가 일어났는가" → "그 이벤트가 예상 밖이었는가" 로 바꿔서 부호 일치율 37% → 54.8% 까지 끌어올림. FOMC 만 보면 57.1% PASS.
  3. B4 (Deep Hedging): 학습을 GBM 합성에서 SPY 일별 실제 수익률 (10년치, fat tail 노출) 로 교체했더니 오히려 +24.5% → +31.3% 로 더 좋아짐 (실시장에서 BSM 이 더 어려워지니 RL 우위가 커짐).
  4. 한화 ELS: DART 추가 다운으로 표본 1 → 4건 (메타) / 2건 정량. 새 1057호는 단일자산이라 모델 가정 한계로 −3.47%, 8286호는 +2.17% 그대로.
  5. C++ MC: 옵션 10만건 동시 재가격 → 1.6분. ELS desk 야간 작업 충분.
  6. 남은 것은 KIS 계좌 발급, KRX 멤버십, 실 자금 거래, 회사 사내 시스템 통합 4개 — 모두 외부 의존이라 입사 후만 가능.
  7. 그래서 결론: "포트폴리오 자체는 거의 production-ready, 마지막 마일은 회사 자원 의존".
