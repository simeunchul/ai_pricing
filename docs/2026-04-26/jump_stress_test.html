한 줄 결과 — 기존 Buehler 정책은 코드 한 줄도 재학습 안 한 채로 jump 환경에서 다음과 같이 buffered: GBM-only +21.28% → 일상잡음 +4.41% → 어닝쇼크 +8.69% → 코로나급 −1.53%. "예측 안 함" 철학 100% 보존 (정책 입력에 jump 신호 0개), 기존 37 pytest + 신규 4 = 41 통과, 학습된 buehler_tc03_v2.pt 그대로 재사용.

1. 무엇을 시도했나 — 배경과 접근

배경 — 사용자 질문 두 가지

  1. "지금 모델은 비정형 변동 (점프, fat-tail) 을 잡을 수 있는가?" → 못 잡는다 (정직)
  2. "비정형성을 추가하면 B4 의 '예측 안 함' 철학이 깨지는가?" → 방식에 따라 다르다

두 가지 추가 방식 — 어떤 것을 골랐나

방식설명철학
A. 환경만 비정형화 ★채택 학습/평가 시뮬에 jump 를 섞음. 정책 입력은 그대로 (5-dim, jump 신호 없음). 정책은 "관측 → 헤지수량" 만 함. 보존 ✓
B. 정책 입력에 jump 예측 신호 추가 "다음 스텝에 jump 올 확률" 같은 feature 를 정책 input 에 끼움. 깨짐 ✗
핵심 구분 — Buehler 의 "예측 안 함" 은 정책 의 성질이지 환경 의 성질이 아니다. 환경이 험해져도 정책이 환경의 미래를 예측하지 않는 한 철학은 그대로다. 방식 A 만 하면 "내 정책은 더 험한 환경에서 학습/평가됐을 뿐, 여전히 미래를 예측하지 않는다" 는 강한 narrative 가 된다.

구현 원칙 — 100% 호환

  • 새 jump 옵션 4개 모두 default 0.0 → 기존 코드/체크포인트 그대로 동작
  • if jump_intensity > 0 분기로 jump 코드 자체를 우회 → λ=0 시 RNG 호출 순서까지 동일 (bit-exact)
  • 기존 학습된 buehler_tc03_v2.pt 를 재학습 없이 stress test 평가에만 사용

2.2 시뮬 step — Merton 1976 jump-diffusion

기존 GBM 한 줄 (정규분포 충격) 을 다음으로 확장: "정규분포 충격 + (이번 step 안에 jump 가 N번 왔다고 가정한 추가 충격)". N 은 매 step 마다 평균 λ·dt 짜리 Poisson 분포에서 뽑고, jump 가 왔으면 그 크기는 다시 log-normal(μJ, σJ²) 에서 뽑는다. 

# λ=0 분기 가드로 기존과 100% 호환
if self.cfg.jump_intensity > 0.0:
    # risk-neutral 보정 (Merton 1976 표준)
    if self.cfg.jump_compensator:
        kappa = math.exp(muJ + 0.5 * sigJ**2) - 1.0
        log_drift -= lam * kappa * dt
    # 이번 step 의 jump 횟수 ~ Poisson(λdt)
    n_jumps = int(self.rng.poisson(lam * dt))
    if n_jumps > 0:
        log_jump = float(np.sum(muJ + sigJ * self.rng.standard_normal(n_jumps)))
S_next = self.S * math.exp(log_drift + log_diff + log_jump)

5. 해석 — 왜 이런 결과가 나왔나

5.1 GBM-only 에서 +21.28% 인 이유 (정상)

학습 분포 그대로. Buehler 의 PG-on-CVaR 가 거래비용 환경에서 제대로 학습된 결과 (이전 보고서의 +24.5% 와 약간 차이는 평가 seed 차이 + 표본 크기 8000).

5.2 Small / Medium jump 에서 +4~9% 인 이유 (놀라운 결과)

핵심 발견 — 정책은 jump 가 있다는 것을 전혀 모른다. 그저 GBM 환경에서 "현재 가격, 시간, 보유 헤지" 만 보고 행동하도록 학습됨. 그런데 Medium jump 환경에서도 BSM Δ 보다 +8.69% 잘함.

왜? Buehler 가 학습한 것은 "특정 분포에 맞춘 헤지" 가 아니라 "거래비용 + 이산 리밸런싱 환경에서 손실 꼬리를 줄이는 일반적 행동 양식". 이 양식은 GBM 가정에 강하게 의존하지 않아서, jump 가 약간 섞여도 깨지지 않는다.

5.3 Large jump 에서 −1.53% 깨진 이유 (정직한 한계)

코로나급 stress 에서는 정책 행동의 디테일 (몇 % 헤지 비율을 잡을지) 자체가 의미 없어진다. jump 한 번에 −8% 갭이 1주에 한 번 와버리면 BSM Δ 도 Buehler 도 큰 손실을 똑같이 떠안음. ratio 가 1 근처로 수렴 — 두 방법의 차이가 사라지는 지점.

5.4 면접 talking point 3 줄

  1. "제 헤지 정책은 학습 환경에 jump 신호가 없었음에도, 분기 어닝쇼크 수준 (λ=10) 의 비정형성에서 BSM Δ 대비 8.69% 우위를 유지했습니다."
  2. "하지만 코로나급 (λ=20) 에서는 1.5% 패배합니다 — 이게 제 모델의 한계 지점입니다."
  3. "이 한계를 넘으려면 jump 환경 자체를 학습 데이터에 섞은 retraining 또는 jump-aware feature 추가가 필요한데, 후자는 Buehler 의 model-free 정신을 깨므로 전자만 추천합니다."

8. 용어 정리집

용어한 줄 설명본문에서의 역할
jump-diffusion 주가가 평소엔 부드럽게 흔들리지만 (diffusion) 가끔 갭으로 점프하는 (jump) 모델 비정형 시뮬 환경의 본체. Merton 1976 가 원조
Merton jump-diffusion 1976년 Merton 의 모델 — jump 횟수는 Poisson, jump 크기는 log-normal 이 stress test 의 환경 모델 그 자체
Poisson 분포 "평균적으로 1년에 λ번 일어나는 사건이 1개월 안에 몇 번 일어날까?" 를 답해주는 분포 jump 횟수를 뽑는 데 사용 (λ=20 → 1년에 평균 20번)
log-normal 분포 로그값이 정규분포인 분포 — 양의 값만 나오므로 "주가 비율 변화" 모델링에 자연스러움 jump 크기 (S 가 몇 배로 변하는지) 의 분포
λ (jump intensity) 1년에 평균 jump 가 몇 번 일어나는가 4 시나리오의 핵심 변수 (0/5/10/20)
μJ (jump mean) jump 가 일어났을 때 log-수익률 평균. 음수면 평균적으로 떨어지는 jump 모든 시나리오에서 음수 (어닝쇼크 = 평균적 −방향)
σJ (jump std) jump 크기의 표준편차. 클수록 jump 의 흩어짐 큼 jump 의 "예측 불가능성" 강도
risk-neutral compensator (κ) jump 가 평균적으로 가격을 끌어내릴 때, 이론적 가격 일관성을 위해 drift 에서 미리 빼주는 보정값 이론 가격 정합성 — jump 환경에서도 "공정 가격" 의미 유지
CVaR@5% 최악의 5% 손실들의 평균 (tail expected loss) 모든 시나리오의 비교 지표 — 작을수록 좋음
BSM Δ-hedge BSM 공식이 알려주는 "현재 σ 에서의 헤지 비율 (Δ)" 만큼 매 step 보유 비교 baseline. 환경 변화를 모르는 단순 헤지
Buehler PG-on-CVaR 거래비용 환경에서 CVaR 손실을 직접 backward 해서 학습한 신경망 정책 이 stress test 의 주인공 — 평가 대상
model-free 정책 가격 모델 (BSM, Heston 등) 의 가정을 정책 입력에 안 쓰는 정책 Buehler 의 정신 — 본 변경에서 보존됨
fat tail 정규분포보다 극단값 (대규모 손실/이익) 이 자주 나오는 분포 모양 jump 의 효과 — 시뮬 PnL 분포가 fat tail 이 됨
bit-exact 호환 같은 입력에 정확히 같은 출력 (부동소수점 비트까지 일치) λ=0 시 기존과 100% 동일 보장 — 기존 모델 재학습 불필요
