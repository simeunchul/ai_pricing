3. Production Runner 설계

scripts/run_kis_paper_trading.py 핵심 기능

기능구현
장중 자동 시작/종료 KST 09:00~15:30 외 자동 대기. 장 마감 시 graceful exit.
장 시작/마감 10분 차단 09:00~09:10, 15:20~15:30 매매 정지 (변동성 큰 구간 제외)
5초 polling KIS API quota 안전. 1분당 12회.
KODEX 200 + 구성종목 10개 시세 매 tick ETF + basket → iNAV 추정
basket fail tolerance 일부 종목 시세 실패 시 cached 가격 사용. 50% 이하 fresh 면 forced HOLD.
iNAV 괴리 ≥ 30bps 매매 EtfInavArbitrage strategy. 청산 5bps.
Risk guard 4-tier 포지션 ≤ 20% / 일일손실 ≤ −1.5% / 시간대 / 에러 9회
SIGINT graceful shutdown Ctrl+C 시 마지막 로그 저장 후 종료
일별 로그 파일 data/kis_trading_log_20260427.json

4. 내일 장중 운영 절차

Step 1 (오늘 저녁 또는 내일 아침 8:50 까지) — 계좌번호 입력

KIS Developers 사이트에서 계좌번호 8자리 확인:

  2. 마이페이지 → 모의투자 → 계좌번호 8자리 복사 (예: 50123456)
  3. .env 의 KIS_ACCOUNT= 뒤에 입력

Step 2 (내일 09:00 이전) — 사전 검증

cd d:\simeunchul\ai_pricing
python scripts/verify_kis.py

4가지 모두 ✓ 나오면 OK. 잔고도 확인됨 (모의투자 1억 default).

Step 3 (내일 09:00~) — 운영

옵션 A: DRY_RUN 모드 (안전 테스트)

.env 의 KIS_DRY_RUN=true 그대로:

python scripts/run_kis_paper_trading.py

→ 시세 받고 신호 발생해도 mock 주문. 가상머니도 안 씀.

옵션 B: 실제 모의투자 매매 (가상머니)

.env 에서 KIS_DRY_RUN=false 로 변경:

# .env
KIS_DRY_RUN=false  ← 변경

# 실행
python scripts/run_kis_paper_trading.py

→ 실제 모의투자 계좌에 가상머니로 매매 (예: KODEX 200 1주 매수 → 가상 9.8만원 차감).

일반 옵션

옵션설명예시

--ignore-hours장 시간 무시 강제 실행(테스트용)

5. 안전 장치 4-tier

Layer차단 조건
1. 환경 변수KIS_DRY_RUN=true 면 모든 주문이 mock
2. 시간대09:10~15:20 외 매매 차단 (장 시작/마감 10분 보호)
3. Risk state일일 손실 −1.5% 초과 시 자동 정지
포지션 ≥ 20% 자본 시 추가 매매 차단
4. Error counterAPI 에러 9회 누적 시 graceful exit
실계좌 운영 절대 금지 (현재 단계) — KIS_ENV=prod + KIS_DRY_RUN=false + --i-understand-live 셋 다 명시해야 가능. 모의투자 (vts) 만 사용.

7. 가능한 문제 + 대응

증상원인대응
토큰 401 키 잘못 입력 또는 만료 verify_kis.py 재실행 → 키 다시 확인
basket coverage 50% 미만 일부 종목 시세 stale (모의투자 한계) 자동 forced HOLD. 매매 안 함. 정상.
주문 거부 (rt_cd != 0) 예수금 부족, 매매 정지 종목 등 로그 확인 → 잔고 조회 → 매매 가능 종목으로
예상보다 신호 안 나옴 iNAV 괴리 30bps 미만 (보통) 정상. KOSPI 대형 ETF 는 평소 5~15bps 수준
일일 손실 −1.5% 도달 큰 변동 + 포지션 자동 정지. 다음 영업일 재시작
