Buehler Jump-Aware Retraining — specialization vs generalization 실증

작성 2026-04-26 · 후속 작업: 사용자 요청 "환경에 비정형 추가, 철학 보존하며 retraining" · 학습: 600 epoch × 16,384 batch × 30 step × 2 모델 (CPU 506초) · 평가: 3 모델 × 4 시나리오 × 8000 path

한 줄 결과 — 정책 입력 5-dim 그대로 (jump 신호 0개) 유지하며 학습 환경만 비정형화. Jump 환경에서 재학습한 정책은 jump 환경에서 BSM Δ 대비 +30.47% (Medium) / +23.19% (Large) 까지 우위 회복. 단 GBM-only 환경에서는 −101.47% 폭망 — ML 고전 trade-off (specialization vs generalization) 의 정확한 재현. Domain-random 학습 모델이 가장 균형 잡힌 robustness (3개 jump 시나리오 모두 +10~27%).

1. 무엇을 시도했나

이전 결과 (jump_stress_test.html) 의 한계

GBM 환경에서 학습한 Buehler 정책을 jump 환경에서 평가했더니 코로나급 (λ=20) 에서 BSM Δ 대비 −1.53% 패배. "어떻게 이 한계를 넘느냐?" 가 자연스러운 질문.

접근 — Buehler 의 model-free 정신을 깨지 않는 두 가지 전략

핵심 제약 — 정책 입력은 5-dim 그대로 (jump 신호 추가 금지). 변경되는 건 학습 데이터의 분포 뿐. 정책은 여전히 환경에 jump 가 있다는 사실을 모름.
전략학습 환경예상 결과
Fixed jump (λ=10) 매 epoch 동일한 jump 분포 (Medium 시나리오와 동일 파라미터) 해당 분포에서 압도적, 분포 외에서 약함 (specialization)
Domain-random 매 epoch 마다 λ ~ Uniform(0, 18) 새로 샘플 (μJ, σJ 도 λ 의 함수) 모든 환경에서 적당한 수준 (generalization)

의도적 train/test split

학습 분포는 λ ∈ [0, 18], 평가 분포는 λ ∈ {0, 5, 10, 20}. Large jump (λ=20) 는 학습 도메인 밖 → OOD generalization 도 측정.

Domain-random 의 분포 디자인

def sample_jump_params(rng):
    lam  = rng.uniform(0.0, 18.0)              # 0 → 18 jumps/year
    muJ  = -0.01 - 0.003 * (lam / 18.0) * 7.0  # mild → severe negative
    sigJ = 0.03 + 0.005 * lam                  # mild → wide spread
    return lam, muJ, sigJ

설계 의도: λ=18 까지만 학습 → λ=20 평가는 의도적 OOD.

4. 해석 — ML 의 No Free Lunch

핵심 통찰 — 어떤 환경에서 학습하느냐에 따라 그 환경에서 가장 강하지만 다른 환경에서 약해진다. "어디서나 1등인 정책은 없다". 이걸 4개 환경 × 3개 모델로 명확히 보여준 게 이 실험의 가치.

4.1 모델별 성격 진단

모델강점약점성격
GBM 학습 (기존) GBM 환경 +21.28% Large jump −1.53% 전문가 (학습 분포에 최적화)
Jump-fixed 학습 Medium +30.47%, Large +23.19% GBM −101.47%, Small −2.88% 편식 — jump 만 잘함, 평온할 때 폭망
Jump-random 학습 3개 jump 시나리오 모두 +10~27% GBM −53.51% (Fixed 보단 나음) 제너럴리스트 — 적당히 다 잘함

4.2 왜 Jump-fixed 가 GBM 에서 −101% 인가?

λ=10 환경에서는 평균적으로 큰 음의 jump 가 자주 온다는 걸 학습 → 정책은 "보수적으로 헤지를 항상 많이 들고 있는" 패턴을 학습. GBM 환경에서는 jump 가 안 오는데 헤지를 무겁게 들고 있으면 거래비용만 누적 → 헤지 비용이 폭발.

즉 정책은 환경의 "통계적 성격" 에 적응한 것이지, 환경 자체를 인식한 것은 아니다. 이게 model-free 의 한계이자 정신.

4.3 왜 Jump-random 이 모든 jump 환경에서 일관된가?

학습 동안 λ 가 0~18 사이를 자유롭게 돌아다녔으므로, 정책은 "어떤 jump 분포가 와도 합리적인 헤지" 를 학습. 특정 환경에서 1등은 못 되지만 어디서도 폭망하지 않음. robustness 의 정의 그대로.

4.4 OOD generalization 의 작은 승리

Jump-random 은 학습 시 λ=20 환경을 본 적이 없는데도 Large jump 에서 +18.30% 개선. "보지 못한 더 험한 환경에서도 어느 정도 일반화" — domain randomization 의 가치를 정량적으로 증명.

5. 실무 권장 — 어떤 모델을 언제 쓰나

시장 상황권장 모델근거
저변동성 / 평온한 시기 (VIX<15) GBM 학습 (기존) +21.28% 우위. jump 가 거의 없으므로 specialization 이 답
중변동성 / 어닝시즌 (VIX 18~25) Jump-random 학습 +10~27% 어디서나 안전. regime 판단 어려울 때 default
고변동성 / 경기 stress (VIX>30) Jump-fixed 학습 (λ=10) +23~30% 압도적. GBM 폭망은 이 시기엔 무관
면접 talking point — "단일 모델로 모든 시장을 커버할 수는 없습니다 (No Free Lunch). 대신 시장 regime 을 분류하고 (예: VIX 분위수, B3 News-IV 시그널) 그 결과에 따라 3개 정책을 교차 사용하는 ensemble 이 실무적 답입니다. AI 기본법 대응 측면에서도 어느 모델을 언제 썼는지 audit log 에 기록하는 게 자연스럽고요."

7. 비전공자용 TL;DR

  1. "평소 시장만 본 헤지 정책 (GBM 학습) 은 평소엔 잘하지만 (+21%) 코로나급 폭락에선 BSM 공식과 비슷해진다 (−1.5%)."
  2. "항상 폭락이 오는 시뮬에서만 학습한 정책 (Jump-fixed) 은 폭락 시 압도적이지만 (+30%) 평온할 땐 거의 100% 망한다."
  3. "매번 다른 시뮬에서 학습한 정책 (Jump-random) 은 어디서나 적당한 수준 (+10~27%) 의 안정성을 갖는다 — generalist."
  4. "세 모델 모두 정책 입력은 똑같이 5-dim. 정책은 jump 가 있다는 사실 자체를 모름. 학습 환경의 성격에만 적응할 뿐."
  5. "실무 답 = '시장 regime 따라 3 모델 교차 사용' 또는 '더 다양한 학습 + 더 큰 정책으로 한 모델로 커버'. 둘 다 정직한 trade-off."

8. 용어 정리집

용어한 줄 설명본문에서의 역할
retraining 같은 모델 구조를 다른 데이터/환경으로 다시 학습 이 작업의 본체 — fixed/random 두 가지 retraining
specialization 특정 분포에 최적화 → 그 분포에서 강하나 분포 외에선 약함 Jump-fixed 의 정확한 정의 (Medium에서 +30, GBM에서 −101)
generalization 다양한 분포에서 적당히 잘함 → 어디서도 폭망하지 않음 Jump-random 의 목표
domain randomization 학습 시 환경 파라미터를 매 에피소드마다 새로 샘플 → 정책이 환경 변화에 robust 해짐 Jump-random 의 핵심 기법 (Sim-to-Real 에서 표준)
OOD (Out-of-Distribution) 학습 시 본 적 없는 분포에서의 평가 Large jump (λ=20) — 학습은 [0,18] 까지만
No Free Lunch (NFL) "모든 분포에서 최적인 단일 정책은 없다" 는 ML 정리 이 실험의 정확한 재현
regime 시장의 큰 분류 (저/중/고변동성 같은 상태) 실무 권장의 핵심 — regime 별 모델 교차 사용
ensemble 여러 정책을 조합해서 사용 — regime 별 분기 또는 가중평균 NFL 을 우회하는 실무적 답
distribution shift 학습 분포 ≠ 평가 분포일 때 성능이 깨지는 현상 Jump-fixed 가 GBM 에서 −101% 인 이유
model-free 가격 모델 (BSM, Heston 등) 가정을 정책 입력에 안 쓰는 정책 설계 Buehler 의 핵심 정신, 본 작업에서 보존
cosine annealing 학습률을 cosine 곡선처럼 천천히 줄이는 방식 두 학습 모두에 사용된 lr 스케줄
CVaR@5% 최악의 5% 손실들의 평균 (tail 손실 척도) 모든 학습/평가의 비교 지표
