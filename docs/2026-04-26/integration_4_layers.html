4-Layer Integration — isolated 검증 → production 통합

2026-04-26 · 5 후보 중 #1, #2, #3, #4 일괄 구현 · 4개 통합 모두 작동 ✓ · 41/41 pytest green

한 줄 결과 — 5 layer 가 isolated 검증 (각 가설 effect 분리 측정) 끝난 후 각 layer 의 결과를 다음 layer 의 입력으로 연결하는 4개 wrapper 일괄 구현. 4개 demo 모두 즉시 작동. 면접 자리에서 "단순 layer 자랑" 이 아니라 "production 시스템 사고" 보여줄 수 있음.

1. 무엇을 시도했는지

배경 — 사용자 진단

"각 layer 가 너무 따로 노는 거 아닌가? B4 헤지 결정에 다른 layer 결과 신경 안 써도 되나?"

완전히 옳은 진단. 5 layer 모두 isolated 동작 검증 완료 후 다음 단계는 통합. 학술 연구는 isolated 가 정답 (effect 분리 측정), production 은 통합이 정답 (각 layer 결과가 다음 layer 의 입력).

5 통합 후보 중 4개 진행 (가성비 큰 순)

#방향현재통합 후
1 B2 → ELS daily NAV ELS 가 σ 직접 입력 매일 시장 IV → calibrated σ 자동 사용 → ELS 일일 NAV
3 B2 → B4 env σ σ=0.20 hardcoded 매일 calibrated σ 로 B4 환경 update
2 B3 → B4 hedge buffer B4 정책이 obs 만 봄 macro shock 감지 시 hedge ratio + buffer
4 B3 → ETF LP spread iNAV 괴리만 shock 감지 시 σ ↑ → spread 1.4× 넓어짐
5 B1/B2 → ELS Heston pricing BSM 가정 (skip — 학술적 가치 ★, 1일+ 작업)

4. #2 B3 → B4 NewsAwareHedger (macro shock 시 hedge 보수성)

구현

파일역할
packages/ai_hedging/.../agents/news_aware_hedger.py NewsAwareHedger wrapper, HedgeBufferRule
Logic: action = clip(base_policy(obs) + buffer, low, high)
buffer = base_buffer + magnitude_scale × |ΔIV| × confidence

실무: BSM Δ 또는 Buehler PG 정책 위에 그대로 plug-in. 정책 재학습 없음.

5. #4 B3 → ETF LP Spread (Avellaneda-Stoikov σ 동적 조정)

구현

파일역할
packages/autotrader/.../strategies/news_aware_lp.py NewsAwareASStrategy: AS 모델 + B3 wrapper
shock 감지 시 σ × shock_multiplier (default 3) → spread 자동 확대

핵심 수식 (왜 σ 가 spread 에 영향)

Avellaneda-Stoikov optimal spread:

spread = γ·σ²·(T−t) + (2/γ)·log(1 + γ/k)

이 식이 말하는 것: 첫째 항은 σ² 에 비례. σ 가 3× 되면 첫째 항이 9× 됨. LP 가 위험할 때 호가 넓혀서 보수적으로.

실행 결과

시나리오eventσbidaskspread
평소neutral 0.20 99.55100.45 0.90
shock (×3)macro_shock 0.60 99.39100.61 1.22
의미: macro shock 감지 → σ 0.20 → 0.60 (×3) → spread 0.90 → 1.22 (1.4× 넓어짐). mid 100 기준 호가가 양쪽으로 0.16 씩 멀어져 위기 시 보수적 LP.
실무: KIS API 로 호가 제출 시 이 wrapper 로 σ 동적 조정. mean-revert 시장은 좁게, trending / shock 시장은 넓게.

6. 통합 전 vs 후 비교

역할통합 전 (isolated)통합 후
한화 ELS 8286호 가격 수동 σ 입력 → 1회 재가격 매일 시장 IV → 자동 NAV 갱신 (#1)
B4 hedge env σ=0.20 fixed (학습 시점만) 매일 시장 IV 로 σ 갱신 (#3)
B4 hedge 결정 obs 5-dim 만 입력 + 뉴스 신호 → shock 시 buffer (#2)
ETF LP 호가 iNAV 괴리만 + fixed σ + 뉴스 신호 → σ 동적 → spread 조정 (#4)

7. 면접 자리 narrative

예상 질문: "5개 layer 다 만들었는데 따로 노는 거 아닌가요?"

답안:
"처음엔 의도적으로 isolated 검증. 각 layer 의 effect 를 분리 측정해야 무엇이 작동/실패인지 명확함 (예: B4 +24.5% PASS, B3 negative result 진단). isolated 검증 완료 후 production 통합 4개 일괄 구현:
• #1 B2 → ELS daily NAV: 한화 8286호 매일 자동 재가격 (10,217 KRW, +2.18%)
• #2 B3 → B4: macro shock 감지 시 hedge +15%p 자동 강화
• #3 B2 → B4 env: σ 0.20 → 0.21 매일 갱신
• #4 B3 → ETF LP: shock 시 σ 3×, spread 1.4× 넓힘
단순 layer 자랑이 아니라 'isolated → 통합' 의 의도된 진행."
