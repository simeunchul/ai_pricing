Layer B4 Deep Hedging — PPO Convergence Tuning v2

quant-lab monorepo · packages/ai_hedging · 2026-04-24

1. Problem Statement

Layer B4 (Deep Hedging) was not converging. 진단 기준 두 가지가 모두 실패 상태였음:

  • TC=0 sanity check: Zero transaction cost 환경에서 PPO 가 BSM Δ-hedge 로 수렴해야 함 (risk-neutral 하에서는 BSM 이 complete-market 최적해). 수렴 실패 시 env/reward 설계 자체가 잘못된 것.
  • TC=0.3% plan target: Proportional TC 30bps 환경에서 PPO CVaR@5% 가 BSM Δ 대비 20% 이상 개선. Buehler et al. 2019 (Quantitative Finance) 핵심 결과 재현이 플랜 목표.

초기 수치 (200k steps PPO, 2000 paths 평가):

TC = 0.0000.7661.852.42xFAIL (sanity)
TC = 0.0031.88220.8311.07xFAIL (plan 20%)

원인 진단 (3가지 추정)

  1. Action space 과잉: Box(-1, 2) 은 call Δ 범위(0~1) 의 3배. 초기 Gaussian exploration (log_std=0 → std=1) 이 유효 범위의 3배를 샘플링 → clipping 빈발, gradient 소실.
  2. Reward sparsity: step reward 는 -0.01·tc, terminal 만 -|pnl|. 30-step episode 에서 per-step PnL variance 신호가 없어 credit assignment 불가.
  3. Step budget 부족: Buehler 원 논문은 수백만~수천만 steps. 200k 로는 탐색 단계도 못 벗어남.

2. 변경 사항

2-1. Action space 축소 — Box(0, 1)

- self.action_space = spaces.Box(low=-1.0, high=2.0, shape=(1,), dtype=np.float32)
+ self.action_space = spaces.Box(
+     low=np.float32(self.cfg.action_low),   # 0.0 for calls
+     high=np.float32(self.cfg.action_high), # 1.0 for calls
+     shape=(1,), dtype=np.float32,
+ )
Call delta ∈ [0, 1] 이 수학적 사실. Put 은 action_low=-1, action_high=0 로 설정. 탐색 공간이 1/3 로 축소되어 PPO 가 유효 영역에서만 샘플링.

2-2. Dense reward shaping (Buehler 2019 eq.13 근사)

# per-step dense shaping: squared replication error
+ V_opt_pre  = BSM_call(S_t, T_rem)            # reference price
+ V_opt_post = BSM_call(S_{t+1}, T_rem - dt)
+ dV_hedged  = cash_{t+1} - cash_t             # portfolio value change
+ rep_err    = dV_hedged - (V_opt_post - V_opt_pre)
+ shape_reward = -shaping_lambda * rep_err**2  # default lambda=50

# terminal reward: CVaR-aware amplification of losses
- reward = -abs(terminal_pnl)
+ if terminal_pnl < 0:
+     reward = -abs(terminal_pnl) * loss_penalty_mult  # mult=5 for TC>0
+ else:
+     reward = -abs(terminal_pnl)
BSM 가격은 reward 신호로만 사용 (학습 중, 시뮬레이션 전용). Inference 시에는 동일한 5-dim state 만 관측. Reward 가 dense 해지면서 PPO 가 step-level credit assignment 가능.

3. Training Curve

가로축: 학습 진행 (좌→우). 세로축: PPO_CVaR / BSM_CVaR 비율. v1 (좌측 빨간 점) 은 완전 미수렴 상태, warm-start (BC) 만으로 TC=0 은 이미 1.10x 근처 도달. TC=0.003 은 fine-tune 200k 시점에서 최적 (0.922) 후 overfitting drift.

PARTIAL 판정: 플랜 목표 20% 개선 미달, 방향성은 일치.

  • 달성: 7.8% 개선 (CVaR 1.882 → 1.736). mean PnL 13% 개선 (덜 TC 깎임) + std 유지.
  • 미달: 기준선 < 0.80x (20% 개선). PPO 가 300k FT 이후 drift 하여 CVaR 재악화 경향. best checkpoint (200k FT, ppo_tc03_cvar.zip) 를 v2 로 고정.

7. Further tuning needed

현재 CPU budget (약 25분 wall-time) 내에서 TC=0.003 의 플랜 목표 20% 에 도달하지 못함. 다음 단계 권장:

  1. CVaR surrogate as primary loss: sample batch 의 5%-tail 만 역전파에 사용 (Distributional RL 또는 RSPG).
  2. Step budget 2M+ with cosine LR schedule: 현재 300k → 2M (CPU 150분).
  3. Randomized market: episode 시작 시 sigma, T, moneyness 를 랜덤화 → generalization 향상, overfitting 방지.
  4. Ensemble of N_seeds: 3~5 seed 로 학습 후 best checkpoint 선택.

본 결과는 models/ppo_tc0_v2.zip, models/ppo_tc03_v2.zip, data/bench_ppo_v2.txt 로 고정. 거짓 보정 없이 실측 그대로 문서화.
