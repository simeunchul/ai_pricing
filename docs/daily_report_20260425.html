4.1 Layer B2 실시장 Heston Calibration 성공

플랜의 "B2 실데이터 calibration" 단계. 이번 세션의 가장 큰 milestone.

Pipeline

  1. scripts/fetch_spy_iv.py: yfinance 로 SPY 옵션 chain (29 expirations × ~108 strikes/expiry = 4,065 IV 점) 수집
  2. 5 moneyness × 5 maturities = 25 cell grid 로 정렬 (interpolation)
  3. scripts/calibrate_spy_heston.py: 학습된 DeepCalibNet 으로 gradient descent on (κ,θ,ξ,ρ,v₀)
  4. Verify: fitted params → semi-analytic IV → market IV RMSE 측정
  5. 비교: scipy.optimize Nelder-Mead 200 iter 와 wall time + accuracy 비교

결과

Methodκθξρv₀RMSEWall
Deep Calib NN 3.1140.07811.000 −0.8810.0451 2.22 vp 2,292 ms
Nelder-Mead 2.5280.07841.137 −0.7940.0433 1.97 vp 32,073 ms
핵심 결과:
• 14× 가속 (32s → 2.3s). 플랜 목표 100× 에는 미달이지만 합성 데이터에서는 26× 였음 — 실데이터에서 학습 분포 밖 영역이라 NN 약간 퍼포먼스 저하.
• ρ ≈ −0.85 (둘 다) → 시장의 leverage effect (주가 하락 시 vol 상승) 정확 포착. 실시장의 well-known stylized fact 와 일치.
• θ ≈ 0.078 → 장기 vol 약 28% 추정. 현재 SPY ATM IV 17~25% 와 일관성.
• v₀ ≈ 0.044 → 단기 vol 약 21%. 현재 ATM IV 와 일치.

5. Deep Hedging 5번 실패 종합 진단

오늘 추가 4번 (v3, v3b, v3c, residual) 합쳐 총 5가지 PPO 변형 모두 실패. 이 패턴 자체가 가장 중요한 finding.

3가지 일관된 실패 메커니즘:
  1. 목적함수 mismatch — PPO 는 E[reward] 최대화, 우리는 CVaR 최소화. 두 함수 직교.
  2. Dense shaping 의 BSM attractor — −λ(V_hedge − V_opt)² 의 minimum 이 정확히 BSM Δ.
  3. Entropy collapse — 학습 길어지면 std → 0, deterministic 됨. residual 도 영향 받음.
결론: hyperparameter 튜닝으로 해결 불가. 알고리즘 변경 필수 (CVaR surrogate / SAC distributional / Buehler 직접 구현).
