4. 솔직한 narrative — 무엇을 배웠나

  1. Sample size 가 결론을 결정. 21일 backtest 의 "buy-hold winner" 가 365일에선 6위. 학술적 정직 = 충분한 데이터 + 한계 인정.
  2. Trailing stop 은 retail 의 진짜 무기. baseline 대비 10배 Sharpe 개선. 단순한 -2% 고정이 정교한 ATR/adaptive 보다 robust.
  3. "Smart filter (multi-factor)" 는 long-term 에서 진짜 alpha. 365일에서 D_trend+funding +42% (1위). 21일에선 -4.92% (4위). 학계 가설 (institutional flow signal) 검증.
  4. 종목별 best 가 다름. 단일 universal strategy 없음. BTC = Bollinger MR, ETH = trend long-only, AVAX/BNB/SOL = trend+funding.
  5. 24h 실거래는 통계 X — 단편 sample. -1.14% 가 strategy 실패 의미 X. 365일 backtest 가 진짜 expected value.
  6. Whipsaw 는 실거래에서 더 잘 발생. AVAX 24h flip 21회 vs backtest 평균 6. 박스권 시장에선 fast/slow MA noise → trail stop 으로도 못 막음.
  7. 사용자 직관이 데이터로 검증됨. Stop-loss/Trailing 추가 가설은 backtest 가 강하게 지지.

5. 면접 narrative (한화 Trading)

"적극적 매매 시스템 설계 + honest limitation reporting":

→ Trading 직군이 가치 있게 보는 점 = "결과 + 그 결과의 한계 정확 측정".

7. 비전공자용 요약 (TL;DR)

3일간 자동매매 봇 만들면서 배운 것:

  1. 1달 backtest 결과는 거의 random. 1년 데이터에서 정반대 결론 나옴.
  2. "Trailing stop -2%" 추가만으로 수익 10배 개선. 단순한 안전망이 정교한 룰보다 효과적.
  3. Smart filter (외국인 매매 같은 신호) 가 1년 데이터에서 진짜 작동. 1달 데이터로 부정 결론 위험.
  4. 종목마다 다른 전략 필요. BTC 와 알트코인 같은 룰로 매매 ❌.
  5. 24h 실거래로 strategy 평가 X. 365일 평균이 진짜 결론. 24h 단편 -1% 는 noise.

한 마디로: "데이터 충분, 안전망 추가, 종목별 차별화" — quant 자동매매의 3원칙.
