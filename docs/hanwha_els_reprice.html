4. 해석 · 면접 자리에서 설명하는 법

왜 base 에서 10,217 > 10,000 인가?

공시 발행가는 투자자 지불가. 발행사의 이론가 (fair value) 는 hedging cost + 마진을 고려한 값. base 시나리오에서 이론가 10,217 → 발행사는 약 2.17% 마진 확보. 실제 한국 ELS 발행 마진은 통상 1~3% 수준이라 base 결과가 업계 상식과 맞음.

KI hit prob 14.1% 의 의미

3년 기간 중 세 자산 최소 ratio 가 50% 이하로 떨어질 확률 14.1%. 1/7 케이스에서 원금 손실 구간 진입. 발행사는 이 구간에서 지급 의무를 헤지하려 기초자산 short + 옵션 매도 포지션 운용. Layer B4 Deep Hedging 이 다루는 문제의 실제 단면.

E[life] 1.45년의 의미

평균 상환까지 1.45년. 즉 대부분 조기상환 (6개월, 1년, 1.5년 시점) 발생. 만기 3년 완주하는 케이스 (KI 관찰 대상) 는 14.1% 뿐. → 실무 현금 흐름 모델링 시 "만기 3년" 이 아니라 "평균 듀레이션 1.45년" 로 감안해야 함.

correlation 민감도

corr=0.9 → price 10,299 (↑), corr=0.2 → 10,186 (↓). 3자산 worst-of 구조에서 correlation 이 높을수록 worst-of 가 덜 극단적 → KI prob 감소 → 투자자 유리 → price 상승. 실무 calibration 실패 시 "correlation = 1 로 단순화" 하면 가격 과대평가 가능성.

5. 한계 및 개선 방향

한계영향해결 방향
KI/autocall barrier 를 DART 에서 직접 못 뽑고 업계 표준 가정 base 결과가 실제 공시와 ±3% 맞는 것은 "가정이 실제와 유사하다" 는 간접 증거. 결정적이지 않음. HTML parser 또는 XML XPath 로 table 순회하며 "95%" "90%" 쌍 추출
